Guia para editar y publicar online en cada practica

  1. Crear la carpeta en el disco duro, se trabaja en local
  2. Abrir el programa Visual Studio Code y arrastrar la carpeta al open folder
  3. Crear new file: index.html
  4. Editar el archivo segun toque
  5. Abrir el navegador y acceder a nuestro perfil de github
  6. Crear un repositorio como el repositorio p1
  7. Ad file y upload file
  8. Una vez el archivo index.html aparece en el directorio de nuestro repositorio, debemos ir a settings, en la barra de la izquierda buscamos pages y en github pages cambiamos a main
  9. Esperar lo que toque, y cuando actualizemos aparecera nuestra url del repositorio en formato webpage, de ahi ya al aules
